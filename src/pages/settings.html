Settings

Nimbus keeps these on this computer. Nothing here leaves it.

How it looks

Theme Sunset is the light one. Dusk is the same colours after dark.
Text size Ctrl and the plus or minus keys do this too, while you are typing.
Line numbers Down the left-hand side of the text.
Wrap long lines Off, and a long line runs off the side with a scrollbar under it.

Typing

Keep the indent on a new line Press Enter and the next line starts where the last one did.
Close brackets and quotes Type one and the other appears. Type it around a selection and it wraps it.
Indent size How far Tab moves the text.
Indent with tab characters Off means spaces. Some files care a great deal which.

Files

Open what was open Your sheets come back next time, unsaved work included.
Save as you go Sheets that already live in a file are written a moment after you stop typing. A sheet that has never been saved is left alone, since autosave should never have to ask where to put something.

Plugins

A plugin is a folder with a plugin.json in it. Everything is switched off until you switch it on. Nimbus takes themes and pages from a plugin and will not run its code — there is nowhere in an editor to run it safely, so the answer is no rather than "carefully".
